# 30-Day Self-Study Validity Controls

This page holds the validity and control checklist extracted from [[30-day-self-study-template-for-nonprescription-interventions]]. Use it before filling [[30-day-self-study-workbook-schema]] so practice effects, caffeine, sleep, expectancy, blinding, meal state, and safety are explicit before the run starts.

## What Changed Since 2024

- The n-of-1 methods literature now gives a clearer shape to practical self-study: recent reviews found a median of six periods, frequent blinding, and common placebo control, but also inconsistent reporting and analysis choices.^[raw/articles/pubmed-38622638-methodological-review-randomized-n-of-1-trials.md]
- The health-psychology n-of-1 review shows that many trials can identify a superior option, but heterogeneity-of-treatment-effect reporting is still thin, which matters if you want to know whether the result is personal or just noisy.^[raw/articles/pubmed-30124759-n-of-1-randomized-intervention-trials-health-psychology-review-critique.md]
- The classic early n-of-1 clinical series remains the clearest proof of concept that a single-person randomized crossover can generate a usable management answer.^[raw/articles/pubmed-2297206-n-of-1-randomized-controlled-trial-clinical-usefulness.md]
- Frequent repeated cognitive testing produces practice effects early on, so a run-in period is not optional if the intervention window is short.^[raw/articles/pubmed-20846444-practice-effects-frequent-repetitive-cognitive-testing.md]
- More recent practice-effect papers show the same issue in older-adult cognition, daily-functioning scales, digital cognitive batteries, and even brief PVT administration, so short-block protocols cannot assume that repeated measures are stable by default.^[raw/articles/pubmed-40844017-short-term-practice-effects-cognition-daily-functioning-older-adults.md]^[raw/articles/pubmed-40911708-practice-effects-digital-cognitive-assessment-tools.md]^[raw/articles/pubmed-29126328-repeated-administration-effects-psychomotor-vigilance-test.md]
- The long-horizon practice-effect literature now shows that repeated testing effects can persist across decades, so familiarization and alternate forms remain important even when the protocol is not short.^[raw/articles/pubmed-40585136-practice-effects-persist-over-two-decades-cognitive-testing.md]
- Alternate forms and explicit warm-up sessions matter because short-interval retest gains can collapse when the form changes and the initial learning run is absorbed.^[raw/articles/pubmed-25994156-written-symbol-digit-modalities-test-alternate-forms-practice-effects.md]^[raw/articles/pubmed-16840238-practice-effects-cogstate-battery-test-retest-intervals.md]
- Short PVTs are valid enough to use in daily field batteries, which gives the template a practical vigilance anchor without forcing a 10-minute test every day.^[raw/articles/pubmed-15354700-validity-pvt-less-than-10-min.md]^[raw/articles/pubmed-17190720-shorter-pvt-substitute.md]
- Sparse smartphone EMA is now feasible enough to use as context tracking without destroying adherence.^[raw/articles/pubmed-39749768-smart-ema-completion-meta-analysis.md]
- Caffeine remains a major confounder because acute benefit can be withdrawal correction, repeated dosing can preserve performance under strain, and repeated exposure can also reshape the state being measured.^[raw/articles/pubmed-22992376-caffeine-attention-withdrawn-consumers.md]^[raw/articles/pubmed-35791877-repeated-low-dose-caffeine-sleep-deprivation-cognition.md]^[raw/articles/pubmed-38830861-repeated-caffeine-intake-sleep-restriction-gm.md]
- Consolidation is now clearly a delayed-retention endpoint, so the template should not treat same-day throughput as the whole story.^[raw/articles/pubmed-40087245-wakeful-rest-memory-consolidation-meta-analysis.md]^[raw/articles/pubmed-21073136-delayed-recall-screening-mci.md]
- Blinding is a measurement problem, not a label. Blinding indices answer different questions, expectancy can move cognition, and withdrawal can masquerade as benefit.^[raw/articles/pubmed-41142043-blinding-indices-comparison-and-application.md]^[raw/articles/pubmed-30861208-expectancy-caffeine-withdrawal-balanced-placebo-design.md]^[raw/articles/pubmed-11502230-placebo-expectancy-glucose-cognition.md]

## Controls That Matter Most

### Sleep

- Keep bedtime and wake time within a narrow window.
- If sleep is unstable, postpone the study instead of trying to analyze noisy data.
- Log sleep duration and subjective sleep quality every day.

### Caffeine

Treat caffeine as part of the protocol, not background noise.

- Fix the caffeine window relative to wake time and first meal; if you move it, you have changed the study.
- If caffeine is not the intervention, keep dose and timing fixed across all blocks, including washout days.
- If caffeine is the intervention, stabilize the baseline habit first and treat the run-in as non-analytic so withdrawal does not masquerade as benefit.
- Use a simple withdrawal score every day during abstinence or washout blocks; note headache, fatigue, irritability, sleepiness, and craving separately if the scale allows.
- If you are using balanced-placebo logic, record the told condition separately from the actual caffeine condition and do the debrief only after the block ends.
- If the study cares about glucose or meal state, keep first meal, fasting window, and postprandial test timing fixed so fed and fasted days are not treated as the same comparator.
- If you are comparing active conditions, keep caffeine, nicotine, and other wake-promoters on the same schedule in every block.
- Do not change caffeine dose mid-study unless that change is the study.

### Learning effects

- Use alternate forms when the task allows it.
- Treat the first few days as practice, not evidence.
- Compare block averages, not single lucky days.

### Practice-effect QC

- Use alternate forms for repeated memory or speed tasks whenever they are available and reasonably equivalent.
- Keep the order of tasks fixed within a session and log it so later analysis can separate order drift from intervention effect.
- For delayed recall, keep the encoding script and the delay window fixed. If either moves, treat it as a different endpoint.
- Give repeated tasks at least one warm-up run before analysis, and add a second warm-up or drop the task as a short-block primary endpoint if the retest still drifts materially.
- If a measure remains unstable after warm-up, mark it as `unstable_for_short_block = yes`.

### Safety

- Use an adverse-event diary every day.
- Stop early for insomnia, anxiety/irritability, palpitations, headache, blood pressure elevation, visual symptoms, or mood destabilization.
