# Non-Hallucinogenic Neuroplastogen Chemical Watchlist

This page is the chemical-first router for non-hallucinogenic psychoplastogens and neuroplastogens that are often discussed as future cognition or brain-fog tools. The current class read is still conservative: [[zalsupindole-dlx-001]] has the strongest human-translation status, [[tabernanthalog]] has the cleanest preclinical cognitive-flexibility signal, and [[2-bromo-lsd]] is mostly a lysergamide mechanism/headache/mood comparator. None has a published healthy-adult cognition win.

## Class Synthesis

The branch is now split into three evidence tiers. Zalsupindole is the first named candidate in this wiki with a visible human phase 1/1b clinical path, but the endpoints are mood, safety, pharmacodynamics, qEEG/PSG biomarkers, and sponsor-reported depression scales, not cognition. Tabernanthalog has the best direct cognitive-flexibility animal result. 2-bromo-LSD is useful mainly because it prevents the class from being reduced to "TBG plus classic microdosing."

The main evidence failure mode is target-engagement-to-behavior inflation. Plasticity, dendritic spines, qEEG, PSG, and non-hallucinogenic assay profiles can all be real while healthy-adult cognition remains unchanged. Until a controlled cognition endpoint appears, this page should stay below mature state-restoration comparators such as [[modafinil]], [[caffeine]], [[fampridine]], [[roflumilast]], or [[methylene-blue-2026-scan]].
