# Translational Gap Table for Cognition Interventions

This page is the wiki's first pass at sorting intervention families by how wide the gap is between preclinical promise and human proof. The main job is not to rank "best nootropics"; it is to identify where animal or mechanism-heavy enthusiasm still outruns durable human evidence, and where the gap has actually narrowed enough to matter.

The table uses three rough buckets:

- `Large gap`: strong preclinical or mechanistic appeal, but thin, negative, or absent human cognition proof.
- `Moderate gap`: human signal exists, but it is protocol-sensitive, phenotype-specific, or not yet durable.
- `Small gap`: human evidence is already substantial enough that the remaining problem is efficacy refinement, not basic translation.

## Readout

The big pattern is that several branches still look "more interesting in animals than in humans." AMPAkines, Dihexa, PNN/ECM manipulation, thymosin beta-4, MOTS-c, and deep-target ultrasound sit in that bucket for broad cognition. The AMPAkine lane is slightly more mature than the others because [[cx717]] now has adult-ADHD symptom data while [[tak-653]] and [[cx1739]] show human target-engagement / PK-safety movement, but the class still lacks a clean healthy-adult efficacy bridge and reads more like a rescue-first salvage path than a broad enhancer class. The PNN lane is even more safety-gated because the positive memory findings come from local extracellular-matrix manipulation. By contrast, intranasal insulin, tPBM, taVNS, HBOT, and incretin therapies are already human branches; their problem is not absence of translation but phenotype, protocol, and comparator quality.

The practical consequence is that future wiki updates should stop treating every mechanistically attractive branch as equally mature. Some branches need more human trials. Others need better stratification. A few mostly need the field to admit that the apparent promise has not made the jump yet.
