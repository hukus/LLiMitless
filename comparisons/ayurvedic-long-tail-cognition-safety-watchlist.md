# Ayurvedic Long-Tail Cognition Safety Watchlist

This page covers traditional-medicine candidates that are visible enough to track but currently sit below the controlled-cognition threshold. The main rule is safety and identity first, cognition claims second.

## Verdict

[[tinospora-cordifolia]] is safety-first: it has modern neuroprotection target hypotheses, but LiverTox and multicenter Indian liver-injury data make it a liver/immune-risk branch before it is a nootropic branch. [[moringa-oleifera]] is a metabolic/nutritional adjunct candidate with broad human exposure but no direct cognition signal. [[nardostachys-jatamansi]] is a preclinical CNS/sleep/neuroprotection lead with no captured human cognition trial. These belong below [[shankhpushpi]], [[centella-asiatica]], [[polygala-bt11]], and [[bacopa]] in practical cognition rankings.^[raw/articles/nature-2025-tinospora-ad-network-metabolomics.md]^[raw/articles/ncbi-bookshelf-2025-livertox-tinospora.md]^[raw/articles/pubmed-41710586-moringa-human-studies-review.md]^[raw/articles/pubmed-38042505-nardostachys-jatamansi-review.md]

## Signal Judgment

This is a coverage page, not a recommendation page. The long-tail Ayurvedic branch is now represented, but the practical evidence ceiling is low. New candidates should be promoted only after direct human cognition endpoints, verified botanical identity, dose/form standardization, and safety monitoring appear.
