# Lamiaceae Aromatic Cognition Watchlist

This watchlist captures the mint-family / aromatic botanical lane after [[sage-salvia-extract]], [[lemon-balm]], and [[phlai-essential-oil-blend]] were already in the graph. The main rule is route discipline: oral extract, oral essential oil, aroma exposure, hydrolat water, dried leaf powder, tea, and formula products are not interchangeable.

## Interpretation

This cluster is not a single mechanism. Some candidates are cholinergic/terpenoid-heavy ([[sage-salvia-extract]], [[peppermint-essential-oil]], [[rosemary-and-1-8-cineole]]), some are stress-state or GABAergic candidates ([[lemon-balm]], [[holy-basil]]), and some are high-polyphenol oral extracts ([[spearmint-extract]]). [[phlai-essential-oil-blend]] is route-specific aromatherapy. The shared lesson is product identity, not shared efficacy.

For healthy adults, the cleanest new candidate is [[spearmint-extract]] because it has multiple controlled studies, including sustained attention in adults aged 18-50. [[peppermint-essential-oil]] and [[rosemary-and-1-8-cineole]] are better read as acute task-state interventions. [[holy-basil]] is best routed through stress, sleep, and cortisol-state cognition. None of these should outrank more established state-restoration tools without replication.^[raw/articles/pubmed-30802720-spearmint-healthy-adults-attention-rct.md]^[raw/articles/pmc-6116079-peppermint-essential-oil-cognition-fatigue-rct.md]^[raw/articles/pmc-3736918-rosemary-cineole-cognition-aroma.md]^[raw/articles/frontiers-2022-holy-basil-holixer-stress-sleep-rct.md]

## Page Gate

- Promote only product-normalized entities: [[spearmint-extract]], [[peppermint-essential-oil]], [[rosemary-and-1-8-cineole]], and [[holy-basil]] now clear standalone thresholds.
- Keep the route label in the page title or first paragraph when possible.
- Do not merge shared marker compounds such as rosmarinic acid, menthol/menthone, linalool, carvone, 1,8-cineole, or eugenol into a single nootropic class.
- Treat aromatherapy and essential-oil routes as safety-sensitive even when trial products look benign.

## Verdict

The Lamiaceae aromatic lane is now broad enough for a reusable watchlist. It contains several low-confidence but real human signals, especially spearmint extract for attention/working memory and rosemary/peppermint for acute demanding-task states. The class remains product-specific, dose-sensitive, and mostly acute or state-restorative.
