# Cognition Intervention Master Table

This page is the wiki's single comparison table for intervention families that have meaningful cognition-relevant evidence. It is intentionally broader than the narrower modality pages: the goal is to keep effect size, confidence, safety burden, cost, protocol complexity, and evidence freshness in one place without repeating the same ranking logic across a dozen hub pages. For the pre-ranking intake gate that decides where a candidate belongs before it reaches this table, see [[molecule-intake-triage-table]]. For timing-sensitive interpretation across device and sleep branches, see [[phase-locked-triad-for-cognition-interventions]].

Read the table as a decision aid, not a cross-family numeric meta-analysis. The effect-size column is a best-current-human-signal snapshot, not a standardized head-to-head estimate.

## Readout Rules

- A row can have a good effect-size snapshot and still be a poor practical choice if the safety burden or protocol complexity is high.
- "Freshness" means the wiki has a substantive 2025-2026 update, not just a new registry entry or a new blog post.
- Rows with mixed or legacy evidence should be read as the current best synthesis, not as settled verdicts.
- Timing and phase alignment can masquerade as effect-size differences, so compare like-with-like before ranking a branch.
