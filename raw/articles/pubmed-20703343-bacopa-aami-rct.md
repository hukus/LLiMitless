# Randomized controlled trial of standardized Bacopa monniera extract in age-associated memory impairment

- PMID: 20703343
- PubMed: https://pubmed.ncbi.nlm.nih.gov/20703343/
- Ingested: 2026-04-27

## Summary

Standardized Bacopa monniera extract was tested in age-associated memory impairment. Participants received 125 mg twice daily for 12 weeks. The extract improved mental control, logical memory, and paired-associate learning versus placebo, making this a foundational standardized-botanical cognition trial.
