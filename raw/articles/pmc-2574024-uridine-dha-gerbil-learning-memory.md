# Dietary Uridine Enhances Learning and Memory Effects of DHA in Gerbils

- PMID: 18606862
- PMCID: PMC2574024
- PubMed Central: https://pmc.ncbi.nlm.nih.gov/articles/PMC2574024/
- Ingested: 2026-05-03

## Summary

Preclinical gerbil study testing dietary uridine monophosphate, choline, and DHA. The paper examined whether compounds that increase brain phosphatides, synaptic proteins, dendritic spines, and neurotransmitter release could improve learning and memory. It is relevant to the uridine / DHA / choline stack hypothesis, but it is animal evidence.

## Interpretation

Use this only as a preclinical mechanism anchor for uridine-containing nootropic stacks. It is not human cognition efficacy evidence.
