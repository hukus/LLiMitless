# Emraclidine phase 2 results in schizophrenia

- ClinicalTrials.gov: NCT05227690
- Source: https://clinicaltrials.gov/study/NCT05227690?tab=results
- Ingested: 2026-04-28

## Summary

AbbVie’s phase 2 emraclidine trial in schizophrenia is completed and has posted results. The registry shows placebo and both dose arms with week-6 PANSS reductions, but the public results page does not provide a clean cognition readout and should be treated as symptom-efficacy surveillance, not enhancement evidence. The posted outcome table is still useful because it confirms the program moved beyond phase 1 and provides a current registry anchor for the branch.
