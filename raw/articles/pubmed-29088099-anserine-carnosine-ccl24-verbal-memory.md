# Anserine/Carnosine Supplementation Suppresses the Expression of the Inflammatory Chemokine CCL24 in Peripheral Blood Mononuclear Cells from Elderly People

- PMID: 29088099
- DOI: 10.3390/nu9111199
- Published: 2017
- Ingested: 2026-05-11

## Summary

Double-blind randomized controlled trial in healthy older adults testing anserine/carnosine supplementation against placebo. Sixty participants completed the study. The active group used 1.0 g/day anserine/carnosine in a 3:1 ratio for 3 months.

Peripheral blood mononuclear-cell analysis found reduced expression of CCL24, an inflammatory chemokine. Verbal memory measured by Wechsler Memory Scale Logical Memory was preserved in the active group. Age-restricted subgroup analyses reported verbal-memory preservation in participants in their 60s and 70s.

## Relevance

This source supports the inflammatory-chemokine / memory-preservation interpretation for [[anserine-carnosine]]. It is relevant to brain-fog hypotheses only as a neuroimmune-adjacent aging signal, not as proof of acute clarity in healthy adults.

## Caveats

- Subgroup analyses are fragile.
- Outcome is preservation, not large improvement.
- The study uses a defined anserine/carnosine ratio and should not be generalized to all carnosine supplements or preworkout beta-alanine.
