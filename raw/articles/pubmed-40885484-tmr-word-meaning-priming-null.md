# No evidence for a targeted memory reactivation effect on word-meaning priming

- PMID: 40885484
- DOI: 10.1016/j.neuropsychologia.2025.109264
- Journal: Neuropsychologia (2025)
- Published: 2025-12-15
- Epub: 2025-08-28
- Design: targeted memory reactivation during a ~2 h nap in 40 of 80 homonyms primed toward their subordinate meaning.

## Captured takeaways

- Word-meaning priming was present overall, but targeted memory reactivation did not add benefit for priming or contextual recall.
- Memory cues increased sleep spindle/beta-band power, which suggests cue-evoked reprocessing even without behavioral gain.
- This is a clean null behavioral result for the sleep-cueing branch, not evidence that the control loop failed to engage the sleep physiology.

## Interpretation for the wiki

TMR can still move sleep physiology without moving the behavioral endpoint, so closed-loop success should stay tied to task-specific outcomes rather than cue-evoked power changes alone.
