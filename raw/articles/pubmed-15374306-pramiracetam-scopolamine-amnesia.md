# Pramiracetam and scopolamine-induced amnesia

PubMed-indexed human pharmacology study of pramiracetam and scopolamine-induced amnesia. The abstract reports that pramiracetam partially reduced scopolamine-induced memory impairment, which makes it a state-challenge / anticholinergic-rescue signal.

The source is not a clean healthy-adult enhancement result because the model uses drug-induced impairment.

Relevance: pramiracetam belongs beside the racetam long tail as a rescue-state comparator.
