# PubMed 30863761: Shilajit anaphylaxis case report

This 2019 Journal of Asthma and Allergy case report describes anaphylaxis to Shilajit.

Case details from the abstract: a 52-year-old woman developed itchy rash, generalized urticaria, dizziness, nausea, sweating, abdominal pain, and loss of consciousness one hour after ingestion of Shilajit prescribed by a practitioner.

Interpretation for the wiki: this is a single case report and does not estimate population risk, but it is a useful safety counterweight to benign-natural-product assumptions.

Relevance: acute hypersensitivity safety signal for [[shilajit]].
