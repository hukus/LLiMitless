# No facilitatory effects of transcranial random noise stimulation on motion processing: A registered report

- PMID: 40669128
- PubMed: https://pubmed.ncbi.nlm.nih.gov/40669128/
- Ingested: 2026-04-28

## Summary

Registered report replication attempt in 42 participants. High-frequency tRNS over hMT+ did not improve motion discrimination, and the authors also found no advantage over sham or forehead stimulation. This is an important counterweight to earlier enthusiasm because it is preregistered and explicitly aimed at replication.

## Notes

Use this as the null anchor for the tRNS branch. It argues against treating tRNS as a robust general-purpose perceptual enhancer.
