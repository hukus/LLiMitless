# The glymphatic system as a therapeutic target: TMS-induced modulation in older adults

- PMID: 40746364
- PMC: https://pmc.ncbi.nlm.nih.gov/articles/PMC12311639/
- Ingested: 2026-04-28

## Summary

2025 sham-controlled TMS study in 36 older adults with mild cognitive impairment. Ten weekday sessions of iTBS, cTBS, and sham were given in randomized order, with DTI-ALPS measured before and after each block and face-name memory testing pre/post. TBS changed glymphatic proxy measures, APOE epsilon4 carriers had lower baseline DTI-ALPS, and within that subgroup TBS-induced DTI-ALPS increases correlated with memory improvements. The main value here is APOE-stratified mechanistic support, not a universal cognition-enhancement claim.
