# Diminished lactate utilization in LDHB-deficient neurons leads to impaired long-term memory retention

- PMID: 39566837
- PubMed: https://pubmed.ncbi.nlm.nih.gov/39566837/
- Ingested: 2026-04-27

## Summary

Mouse and cell work showing that impaired neuronal lactate utilization correlates with worse long-term memory retention. The study complicates the simple astrocyte-to-neuron story by suggesting that both lactate supply and neuronal lactate-handling capacity matter for cognition.
