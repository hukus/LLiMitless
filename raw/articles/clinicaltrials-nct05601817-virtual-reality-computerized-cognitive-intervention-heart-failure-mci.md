# Virtual Reality and Computerized Cognitive Intervention for Mild Cognitive Impairment in Heart Failure

- ClinicalTrials.gov ID: NCT05601817
- Study page: https://clinicaltrials.gov/study/NCT05601817
- Ingested: 2026-04-29

## Summary

Randomized factorial trial in older adults with heart failure and mild cognitive impairment testing a virtual reality-based cognitive restoration intervention (Vita), computerized cognitive training (Com), and the combination versus standard of care.

The current record reports 172 estimated participants, 2025-05-06 as last update posted, and estimated completion on 2026-12-31. It is an explicit phenotype-enriched, combination-style pipeline item rather than an enhancement claim.

## Notes

This record is useful because it separates the VR restoration component from the computerized training component, which is exactly the sort of decomposition the branch needs.
