# Transcranial photobiomodulation improves functional brain networks and working memory in healthy older adults: An fNIRS study

- PMID: 40482941
- PubMed: https://pubmed.ncbi.nlm.nih.gov/40482941/
- Ingested: 2026-04-27

## Summary

Randomized sham-controlled crossover study in healthy older adults. Active 1064-nm tPBM improved 3-back accuracy and reaction time and increased functional connectivity and graph-theoretic efficiency. This is the clearest recent healthy-adult signal in the tPBM cluster.
