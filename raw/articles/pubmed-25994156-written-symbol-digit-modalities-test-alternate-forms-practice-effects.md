# Repeated Assessment and Practice Effects of the Written Symbol Digit Modalities Test Using a Short Inter-Test Interval

- PMID: 25994156
- PubMed: https://pubmed.ncbi.nlm.nih.gov/25994156/
- Ingested: 2026-04-28

## Summary

2015 study of two alternate written SDMT forms over a 150-minute retest interval found large practice effects when the same form was repeated and little to none when different forms were used. This is direct evidence that alternate forms can materially reduce short-interval retest gains.

## Notes

The result supports using alternate forms wherever a repeated endpoint is likely to be used in short blocks or digital follow-up.
