# Targeted memory reactivation during sleep modulates spindle and slow wave density, but not motor memory consolidation, in Parkinson's disease

medRxiv 2026 preprint in 20 people with Parkinson's disease and 20 healthy older adults. Auditory TMR during a 2-hour nap did not improve motor retention or dual-task performance in either group. It did increase slow-wave density and decrease spindle density, and slow-wave amplitude during cue presentation was positively associated with performance in healthy older adults.

This is a disease-context null on behavior with a physiology-only signal. It is useful for the branch because it keeps the sleep-physiology effect separate from any claim of motor-memory rescue.
