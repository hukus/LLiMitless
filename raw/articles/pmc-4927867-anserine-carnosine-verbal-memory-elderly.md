# Effect of Anserine/Carnosine Supplementation on Verbal Episodic Memory in Elderly People

- PMCID: PMC4927867
- Published: 2016
- Ingested: 2026-05-11

## Summary

Double-blind randomized controlled trial testing whether anserine/carnosine supplementation could preserve cognitive function in older adults. The active arm used 1.0 g/day of an anserine/carnosine formula in a 3:1 ratio for 3 months. Thirty-nine healthy volunteers aged 60-78 completed follow-up testing.

Delayed recall verbal memory on the Wechsler Memory Scale Logical Memory task was preserved in the active group versus placebo, p = 0.0128. Blood analysis showed lower secretion of inflammatory cytokines, including CCL2 and IL-8. Arterial spin labeling MRI suggested suppression of age-related posterior cingulate blood-flow decline in the active group, p = 0.0248.

## Relevance

Useful human trial for [[anserine-carnosine]] because it links a selected delayed-memory result to inflammatory cytokine and brain-perfusion markers. It is still a small older-adult preservation study rather than healthy baseline enhancement proof.

## Caveats

- Small completed sample.
- Three-month intervention and older cohort limit generalization.
- The strongest cognitive signal is delayed verbal memory preservation.
- Biomarker movement should not be treated as proof of everyday cognitive transfer.
