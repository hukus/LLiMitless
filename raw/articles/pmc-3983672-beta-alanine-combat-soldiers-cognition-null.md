# Beta-alanine supplementation improves tactical performance but not cognitive function in combat soldiers

- PMCID: PMC3983672
- DOI: 10.1186/1550-2783-11-15
- Published: 2014-04-10
- Ingested: 2026-05-11

## Summary

Trial of beta-alanine supplementation in combat soldiers under a military performance frame. The study rationale was that beta-alanine might help maintain physical and cognitive performance under high-intensity military activity and stress.

The title-level and abstract-level result is split: tactical / physical performance improved, but cognitive function did not.

## Relevance

Important null counterweight for [[beta-alanine]]. It prevents translating ergogenic or tactical-performance findings into cognitive-enhancement claims.

## Caveats

- Military stress/task context differs from ordinary healthy-adult use.
- The study still supports a physical-performance / fatigue-resilience route, not a cognition route.
- Cognitive tasks and stressor context should be checked before using it as a generalized null.
