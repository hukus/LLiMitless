# Phase-lagged tACS between executive and default mode networks modulates working memory

- PMID: 40097468
- PubMed: https://pubmed.ncbi.nlm.nih.gov/40097468/
- Ingested: 2026-04-30

## Summary

Phase-lagged tACS between the central executive and default mode networks modulated working-memory performance in a phase-dependent way, with 45° and 180° lags producing different behavioral and fMRI/connectivity patterns. The study is useful because it shows phase lag, target pairing, and deep-network coupling are part of the parameter-response space, not just current intensity or frequency.

## Notes

The abstract emphasizes task performance differences reflected in hippocampal activation and task-related functional connectivity. The protocol used tACS only during the retention period of a Sternberg task, which makes it a strong timing/phase-control example for the tACS branch.
