# Decreased Oxytocin Mediates PVN-CA2 and PVN-PrL in Sleep Deprivation-Induced Social Memory Deficits

- PMID: 41660638
- PMCID: PMC12877408
- PubMed: https://pubmed.ncbi.nlm.nih.gov/41660638/
- Publication date: 2026-02-06

## Summary

Preclinical sleep-deprivation study showing that reduced oxytocin release contributes to social-memory deficits. Optogenetic activation of oxytocin-linked pathways restored or protected social memory in mice.

## Notes

- Source type: animal mechanistic study.
- Main finding: chronic sleep deprivation reduced oxytocin release in hippocampal CA2 and prelimbic cortex, disrupting encoding and retrieval of social memory.
- Rescue: pathway-specific optogenetic activation transiently restored deficits; high-frequency activation sustained protection.
- Interpretation: this is a causal sleep-loss / social-memory mechanism paper, not human cognition evidence.
