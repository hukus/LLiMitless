# Odor-Cued Targeted Reactivation Was Unable to Selectively Benefit Declarative Memories During Sleep

J Sleep Res 2026 study in 32 participants. Two object-location learning sets were paired with distinct odors, and one odor was cued during NREM sleep. The cued category did not outperform the non-cued one overall. A more nuanced effect depended on initial encoding strength, and odor presentation produced a sustained ~15 s inhibition in sigma activity rather than the expected sigma boost.

This is an important 2026 null for selectivity: odor cueing may generalize across the learning context rather than selectively enhancing a single set of declarative memories.
