# Exogenous ketone salts do not improve cognitive responses after a high-intensity exercise protocol in healthy college-aged males

- PMID: 29451991
- Study type: randomized controlled trial
- Population: 15 healthy college-aged males
- Intervention: 11.38 g beta-hydroxybutyrate beverage vs placebo before repeated Wingates
- Challenge: 5-minute FitLight response task before and after repeated high-intensity cycling
- Signal: no cognitive benefit
- Caveat: ketone salt, not ketone ester

## Summary

This is an important null because it shows that not every exogenous-ketone formulation helps under heavy load; dose, formulation, and context likely matter.
