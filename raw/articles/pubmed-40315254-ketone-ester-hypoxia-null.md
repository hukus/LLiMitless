# Ketone ester ingestion impairs exercise performance without impacting cognitive function or circulating EPO during acute hypoxic exposure

- PMID: 40315254
- Study type: randomized crossover double-blind trial
- Population: 19 participants, with microneurography subset
- Intervention: oral ketone monoester 0.4 g/kg vs placebo
- Stressor: acute severe hypoxia plus stress tasks
- Signal: no cognitive benefit in this hypoxic context; exercise performance worsened

## Summary

This is a useful null for the "high-load resilience" narrative because it shows the ketone ester does not automatically rescue cognition under hypoxic stress.
