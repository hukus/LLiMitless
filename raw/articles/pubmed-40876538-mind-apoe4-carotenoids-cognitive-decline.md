Title: Apolipoprotein E ε4-dependent associations between carotenoids and cognitive decline: Findings from the MIND randomized controlled trial

This MIND-trial analysis asks whether APOE ε4 status changes the relationship between carotenoids and cognitive decline.

Its value for this topic is that it shows effect modification inside a large randomized nutrition trial. That is a reminder that biomarker-enriched or biomarker-stratified analysis can reveal heterogeneity that the average trial effect may conceal.

It is still an association analysis within an RCT, not a prospective enriched-enrollment test of a cognition intervention.
