# Oral Orexin Receptor 2 Agonist in Narcolepsy Type 1

- PMID: 37494485
- PubMed: https://pubmed.ncbi.nlm.nih.gov/37494485/
- Ingested: 2026-04-27

## Summary

Phase 2 randomized placebo-controlled trial of TAK-994 in narcolepsy type 1. The drug improved wakefulness and cataplexy, but the program was complicated by clinically important liver-enzyme elevations and Hy's-law drug-induced liver injury in some participants. This is an important proof-of-mechanism source for the orexin-agonist branch, but not a viable general-performance precedent.
