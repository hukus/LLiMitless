# Memory reactivation during rest forms shortcuts in a cognitive map

- PMID: 40634342
- PubMed: https://pubmed.ncbi.nlm.nih.gov/40634342/
- Published: 2025-07-09

## Summary

2025 Scientific Reports study using awake contextual targeted memory reactivation during rest. The result is not just stronger direct memory: reactivation qualitatively reorganized the cognitive map by creating inferred shortcuts between events not directly experienced together.

## Notes

Important for plasticity budgeting because it shows offline rest can support reorganization, not only passive consolidation. It also adds a caution: shortcut formation improved inference but reduced rapid update flexibility.
