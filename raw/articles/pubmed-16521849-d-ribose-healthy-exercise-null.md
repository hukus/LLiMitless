# PubMed 16521849 D-ribose healthy exercise performance null

This PubMed-indexed healthy-adult exercise study tested whether D-ribose supplementation improved high-intensity exercise performance. The exact endpoints were physical-performance and recovery measures rather than cognition.

Result: the abstract-level signal is a null or non-supportive result for performance enhancement in healthy subjects under the tested exercise conditions.

Interpretation for the wiki: this is a useful counterweight to "ATP restoration" marketing. Even in healthy exercise contexts, D-ribose should not be assumed to improve performance, and no cognition endpoint was measured. It supports keeping D-ribose below [[creatine]], [[ketone-ester]], lactate, and caffeine in the energy-substrate cognition map.
