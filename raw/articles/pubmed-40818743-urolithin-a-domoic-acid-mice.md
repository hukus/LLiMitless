# Urolithin A protects against domoic acid-induced cognitive deficits via promoting estrogen receptor-alpha-mediated mitochondrial biogenesis signaling in mice

- PMID: 40818743
- PubMed: https://pubmed.ncbi.nlm.nih.gov/40818743/
- Ingested: 2026-04-28

## Summary

2025 mouse cognition paper reporting that urolithin A protected against domoic-acid-induced cognitive deficits, with the proposed route involving estrogen receptor-alpha-mediated mitochondrial biogenesis signaling.

Use in the wiki: this is a preclinical cognition-rescue anchor for the urolithin A branch. It supports mechanistic plausibility for mitochondrial / mitophagy-related cognition hypotheses, but it does not establish human cognitive benefit.
