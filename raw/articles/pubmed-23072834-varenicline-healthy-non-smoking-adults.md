# Effects of short-term varenicline administration on emotional and cognitive processing in healthy, non-smoking adults: a randomized, double-blind, study

- PMID: 23072834
- PubMed: https://pubmed.ncbi.nlm.nih.gov/23072834/
- Ingested: 2026-04-27

## Summary

Short-term varenicline in healthy non-smoking adults did not change mood, negative emotional bias, or impulsivity, but it did improve working memory and declarative memory versus placebo in a 38-person randomized study. This is the cleanest direct nicotinic-enhancement signal in the current branch, but the sample is small and the effect is not yet replicated in newer healthy-adult cognition trials.
