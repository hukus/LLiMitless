# Long-term effects of bifrontal transcranial alternating current stimulation on verbal working memory and episodic memory in young healthy adults

- PMID: 41461804
- PubMed: https://pubmed.ncbi.nlm.nih.gov/41461804/
- Ingested: 2026-04-30

## Summary

Five consecutive bifrontal tACS sessions improved verbal working memory at 4 weeks post-intervention and also increased episodic memory accuracy, but not immediately after treatment. The study also reported lower left prefrontal theta power in the active group, which makes it a useful retention and electrophysiology anchor for the tACS branch.

## Notes

The abstract suggests a delayed plasticity effect rather than a same-day performance effect, so it should be treated as a durability-positive but time-dependent source. The EEG component also makes it useful for parameter-response mapping because it connects stimulation schedule with a physiological readout.
