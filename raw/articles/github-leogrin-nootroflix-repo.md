# LeoGrin/nootroflix

- Source type: public code/data repository backing a nootropic recommender system
- Related analysis: Troof nootropic ratings analysis
- Repository contents: `data/data_with_ssc.csv`, `data/data_without_ssc.csv`, `data/dataset_clean_right_names.csv`, `data/nootropics_metadata.csv`

## Summary

This repository is the public code/data backend for the Troof recommendation system. It confirms that the analysis is based on a merged SSC + newer-user dataset and that the published post rests on a recommender-model workflow rather than a simple tabular survey export.

## Caveats

- The repository exposes open-label self-report data and analysis code, not controlled evidence.
- Item labels, cleaning, and filtering choices are analysis-dependent.
