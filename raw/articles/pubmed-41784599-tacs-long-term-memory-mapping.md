# Mapping Long-Term Memory Modulation With Transcranial Alternating Current Stimulation

- PMID: 41784599
- PubMed: https://pubmed.ncbi.nlm.nih.gov/41784599/
- Ingested: 2026-04-28

## Summary

2026 meta-analytic field-mapping paper for tACS and long-term memory. The results suggest frequency- and site-specific effects, with theta and gamma showing different spatial patterns and some nonlinear intensity-response behavior.

## Notes

This source matters because it adds a more anatomical view to the tACS branch: not just "theta is better," but which cortical regions show positive, negative, or nonlinear associations with memory outcomes.
