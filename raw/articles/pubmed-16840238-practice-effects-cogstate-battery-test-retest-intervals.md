# Practice effects associated with the repeated assessment of cognitive function using the CogState battery at 10-minute, one week and one month test-retest intervals

- PMID: 16840238
- PubMed: https://pubmed.ncbi.nlm.nih.gov/16840238/
- Ingested: 2026-04-28

## Summary

CogState battery study across 10-minute, one-week, and one-month intervals found practice effects mainly between the first and second administrations, with early stabilization after a warm-up and no practice effects at one month once the initial practice run was absorbed. This is the cleanest direct support for a familiarization phase before short-block measurement.

## Notes

The interval itself changes what looks like signal, so fixed delay windows and a deliberate warm-up are part of the measurement definition.
