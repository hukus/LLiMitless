# Effects of mPFC-rTMS in chronic Insomnia: A randomized, double-blind, placebo-controlled study

- PMID: 40774161
- PubMed: https://pubmed.ncbi.nlm.nih.gov/40774161/
- Ingested: 2026-04-27

## Summary

Pilot randomized sham-controlled rTMS trial in chronic insomnia using 20 sessions targeting the medial prefrontal cortex. Active rTMS improved response and remission rates versus sham.

## Notes

This is sleep-state evidence for neuromodulation, but it does not show a direct cognitive-enhancement endpoint. It is still relevant because it suggests stimulation can be used to change the insomnia state that CBT-I would also target.
