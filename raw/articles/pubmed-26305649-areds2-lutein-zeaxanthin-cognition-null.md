# AREDS2 cognition trial for omega-3, lutein, zeaxanthin, and related nutrients

- Source type: large randomized clinical trial / cognitive ancillary study.
- Publication: JAMA, 2015.
- Date checked: 2026-05-11.

AREDS2 tested whether adding long-chain omega-3 fatty acids and / or lutein plus zeaxanthin to an eye-health supplement background affected cognitive function in older adults followed for years. The study is important because it is much larger and longer than the smaller positive xanthophyll cognition trials.

The main cognition result was null: supplementation with omega-3 fatty acids, lutein plus zeaxanthin, or the tested nutrient combinations did not produce a meaningful cognitive benefit in this population.

Use in the wiki: this is the largest counterweight for [[lutein-zeaxanthin]]. It prevents the page from treating smaller positive memory / attention trials as broad cognitive-aging proof.
