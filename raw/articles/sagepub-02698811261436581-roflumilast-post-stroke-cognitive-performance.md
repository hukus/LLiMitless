# The effects of the PDE4 inhibitor roflumilast on cognitive performance after a cerebrovascular accident: a double-blind randomized placebo-controlled trial with an open label extension (ROSTMEMA)

- DOI: 10.1177/02698811261436581
- First published online: 2026-04-24
- Ingested: 2026-04-28

## Summary

2026 double-blind randomized placebo-controlled trial in post-stroke cognitive impairment (PSCI). Community-dwelling adults 41-70 years old, more than a year after cerebrovascular accident, with subjective memory complaints and below-normative delayed recall, received roflumilast 100 micrograms daily or placebo (50 per group), followed by a 3-month open-label extension in 42 placebo participants. The primary ANCOVA showed a larger response in the roflumilast arm on delayed verbal learning and Rivermead Behavioural Memory Test stories at endpoint with non-significant moderate effect sizes; post hoc adjustment for baseline prognostic covariates made the effect significant. Open-label extension memory scores improved with medium-to-large effect sizes. Adverse events were similar in both groups.

## Key Points

- Primary phenotype: PSCI with subjective memory complaints.
- Dose: 100 micrograms once daily.
- Sample: 97 completers, 48 roflumilast and 49 placebo.
- Interpretation: the strongest newer human roflumilast result so far, but the effect remains modest and analysis-sensitive.
