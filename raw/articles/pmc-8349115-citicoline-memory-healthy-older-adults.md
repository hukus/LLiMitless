# Citicoline and Memory Function in Healthy Older Adults

- PMID: 33978188
- PMCID: PMC8349115
- PubMed Central: https://pmc.ncbi.nlm.nih.gov/articles/PMC8349115/
- DOI: 10.1093/jn/nxab119
- Ingested: 2026-05-03

## Summary

Randomized, double-blind, placebo-controlled trial in 100 healthy men and women aged 50-85 with age-associated memory impairment. Participants received 500 mg/day citicoline or placebo for 12 weeks. Ninety-nine participants completed the study. Citicoline improved secondary episodic-memory and composite-memory outcomes compared with placebo, while the source reported no concerning safety imbalance in body weight, blood pressure, hematology, metabolic panels, or adverse-event queries.

## Interpretation

This is a low-to-moderate formal signal for older adults with age-associated memory impairment. It is not evidence for broad young healthy-adult enhancement, and the branded-product / sponsor context should be preserved when using it in the choline-donor branch.
