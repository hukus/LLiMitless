# Boswellia serrata plus Melissa officinalis older-adult memory RCT

PubMed-indexed 2018 randomized double-blind placebo-controlled trial of a tablet containing Boswellia serrata extract plus Melissa officinalis extract in older adults.

Design: 70 older adults were randomized to active tablets or placebo for 1 month; the study was completed by 53 participants, but the abstract says intention-to-treat analysis included all 70. Memory was measured with the Wechsler Memory Scale-Revised.

Results: WMS-R total score and subscales including auditory immediate, immediate memory, visual immediate, and working memory increased after the Boswellia plus Melissa tablet relative to placebo.

Relevance: memory-positive older-adult trial, but combination-only. It cannot isolate lemon balm from Boswellia serrata or from the specific tablet formulation.
