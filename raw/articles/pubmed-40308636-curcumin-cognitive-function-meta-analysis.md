# The effect of curcumin supplementation on cognitive function: an updated systematic review and meta-analysis

- PMID: 40308636
- PubMed: https://pubmed.ncbi.nlm.nih.gov/40308636/
- Ingested: 2026-04-27

## Summary

2025 meta-analysis of nine RCTs with 501 participants found improved global cognitive function with curcumin versus placebo. It is a signal worth tracking because the intervention is chemically standardizable, but the evidence base is still small and mixed across prior reviews.
