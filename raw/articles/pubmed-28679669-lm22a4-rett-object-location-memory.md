# A small-molecule TrkB ligand restores hippocampal synaptic plasticity and object location memory in Rett syndrome mice

- PMID: 28679669
- DOI: 10.1242/dmm.029959
- Journal: Disease Models & Mechanisms
- Year: 2017
- Ingested: 2026-05-04

## Summary

Preclinical Rett syndrome mouse study of the BDNF receptor TrkB ligand LM22A-4. Female Mecp2 heterozygous mice received systemic LM22A-4 for 4 weeks. Treatment improved hippocampal-dependent object location memory and restored hippocampal long-term potentiation. Mechanistically, LM22A-4 dampened hyperactive hippocampal network activity, reduced miniature excitatory postsynaptic current frequency and amplitude, and reduced spontaneous tetrodotoxin-resistant calcium-signal frequency toward wild-type-like features.

## Notes

- Use as the strongest cognition-relevant LM22A-4 source in the current corpus.
- This is disease-model and mouse evidence, not human cognition efficacy.
- Interpretation belongs in the TrkB target-specificity gate because LM22A-4 is a small-molecule partial agonist / BDNF-loop mimetic with translation and specificity uncertainty.
