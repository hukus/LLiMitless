# The effect of spermidine on memory performance in older adults at risk for dementia

- PMID: 30388439
- PubMed: https://pubmed.ncbi.nlm.nih.gov/30388439/
- Ingested: 2026-04-28

## Summary

2018 placebo-controlled, double-blind phase IIa pilot trial in subjective cognitive decline. A spermidine-rich plant extract was associated with a moderate improvement in mnemonic discrimination, making this the cleanest direct human cognition signal in the spermidine branch.
