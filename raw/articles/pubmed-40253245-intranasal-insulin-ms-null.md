# Intranasal insulin for improving cognitive function in multiple sclerosis

- PMID: 40253245
- PubMed: https://pubmed.ncbi.nlm.nih.gov/40253245/
- Ingested: 2026-04-27

## Summary

Phase Ib/II randomized double-blind placebo-controlled trial in people with MS and cognitive impairment. Intranasal insulin was safe and well tolerated, but SDMT and secondary outcomes did not differ from placebo.

## Notes

This is a clear null for the MS phenotype and a useful reminder that delivery route and disease label do not guarantee a cognition signal.
