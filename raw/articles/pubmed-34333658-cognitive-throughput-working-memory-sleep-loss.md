# Cognitive throughput and working memory raw scores consistently differentiate resilient and vulnerable groups to sleep loss

- PMID: 34333658
- PubMed: https://pubmed.ncbi.nlm.nih.gov/34333658/
- Ingested: 2026-04-27

## Summary

2021 sleep-loss study reporting that cognitive throughput and working-memory raw scores distinguish sleep-loss-resilient from sleep-loss-vulnerable groups. It supports using throughput-like measures as a resilience endpoint when the intervention is supposed to preserve performance under strain rather than raise resting baseline scores.

## Notes

This is one of the cleaner anchors for the "resilience" bucket because the phenotype is defined by performance under a perturbation.
