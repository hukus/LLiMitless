# NICOTINE TRANSDERMAL SYSTEM patch, extended release

## Summary

OTC nicotine patch used as a stop-smoking aid. The label says nicotine can increase heart rate and blood pressure, and it advises removing the patch at bedtime if vivid dreams or sleep disturbance occur.
