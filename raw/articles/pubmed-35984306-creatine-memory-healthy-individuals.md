# Effects of creatine supplementation on memory in healthy individuals: a systematic review and meta-analysis.

- PMID: 35984306
- PubMed: https://pubmed.ncbi.nlm.nih.gov/35984306/
- Ingested: 2026-04-27

## Summary

2023 meta-analysis of healthy individuals found creatine improved memory overall, with the clearest signal in older adults and little signal in younger adults.

## Notes

This older review is still useful because it separates the age-sensitive memory effect from the broader adult meta-analysis.
