# An experimental medicine study of the phosphodiesterase-4 inhibitor, roflumilast, on working memory-related brain activity and episodic memory in schizophrenia patients

- PMID: 30536081
- PubMed: https://pubmed.ncbi.nlm.nih.gov/30536081/
- Ingested: 2026-04-27

## Summary

2018/2021 experimental-medicine crossover study in schizophrenia. Roflumilast 250 micrograms improved verbal memory versus placebo, but working memory did not improve. The signal was strongest for episodic/verbal memory, not the full cognitive profile.

## Key points

- Design: 15 schizophrenia patients, placebo and two roflumilast doses, 8 days each with washout.
- Outcome: fMRI DLPFC activation, verbal memory, working memory.
- Signal: verbal memory effect size around 0.77 at 250 micrograms.
- Interpretation: supports PDE4 inhibition as a plausible cognition target in schizophrenia, but the effect is narrow.
