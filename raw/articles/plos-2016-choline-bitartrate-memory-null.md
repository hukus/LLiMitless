# No acute effects of choline bitartrate food supplements on memory in healthy, young, human adults

- DOI: 10.1371/journal.pone.0157714
- Journal: PLOS ONE
- Year: 2016
- Ingested: 2026-05-04

## Summary

Three double-blind placebo-controlled crossover experiments tested acute choline bitartrate in healthy young students. Experiment 1 included 28 participants and a visuospatial working-memory task; experiment 2 included 26 participants and a declarative picture-memorization task; experiment 3 included 40 participants and verbal working memory plus visuospatial and declarative tasks. Tasks occurred roughly 60 minutes after 2.0-2.5 g choline bitartrate or placebo. Choline did not significantly enhance any memory task, and Bayesian analyses supported the null hypothesis. The authors concluded that choline likely has no acute effects on cholinergic memory functions in healthy humans.

## Notes

- Use as the key memory-null counterweight for choline bitartrate.
- This should not erase the separate 2015 visuomotor-precision signal; it narrows it.
- The study is healthy-young-adult only and acute, so it does not rule out deficient, older, or impairment-context effects.
