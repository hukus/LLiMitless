# Blueberry supplementation improves memory in older adults

- Source type: small human intervention study / preliminary clinical trial.
- Publication: Journal of Agricultural and Food Chemistry, 2010.
- Date checked: 2026-05-03.

This preliminary 12-week study tested daily wild blueberry juice in 9 older adults with early memory changes. It reported improved paired associate learning and word-list recall after supplementation, with trends toward reduced depressive symptoms and lower glucose.

The authors also compared the blueberry participants with a demographically matched berry-placebo companion group and found similar paired-associate-learning support. The study is useful as an early human memory signal, but the sample was very small and should be treated as hypothesis-generating rather than decisive.

Use in the wiki: early blueberry / anthocyanin memory anchor for older adults with memory complaints. It supports standalone visibility only when paired with later RCTs and meta-analytic evidence.
