# Impact of a Novel Brain Longevity Supplement Containing the Postbiotic Urolithin A (Mitopure) on Cognitive Function and Related Health Outcomes

- ClinicalTrials.gov: NCT07060898
- Ingested: 2026-05-03

## Summary

ClinicalTrials.gov record for CLARITY / RADX-SP-2506_RAM, a randomized, double-blind, placebo-controlled direct-to-consumer study of an active nutritional product containing Mitopure urolithin A versus identical placebo in U.S. adults with aging / cognitive decline / brain fog / cognitive function framing.

The record was active, not recruiting, with last update posted 2026-03-06. It lists actual enrollment of 650, actual study start 2025-07-29, actual primary completion 2025-11-20, and estimated study completion 2026-11-20. No results are posted in the public registry as of this capture.

The primary outcome is change in PROMIS Cognitive Function 8A over 8 weeks. Secondary outcomes include PROMIS fatigue, PROMIS sleep-related impairment, PROMIS cognitive abilities, DANA Brain Vital app cognitive assessments, minimal clinically important difference analyses, and adverse events.

Use in the wiki: this is the current direct-cognition human registry anchor for urolithin A, but it is not yet efficacy evidence. The design is large for a supplement registry, but the primary endpoint is self-reported cognitive function and the result is pending.
