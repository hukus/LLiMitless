# Alleviation by Fisetin of Frailty, Inflammation, and Related Measures in Older Adults

- ClinicalTrials.gov ID: NCT03675724
- Study name: AFFIRM-LITE

## Summary

This is a placebo-controlled fisetin study in older adults that focuses on frailty and inflammation rather than cognition. It is useful as the main human fisetin anchor for the senescence branch.

## Key Data

- Design: phase 2 randomized, placebo-controlled pilot.
- Population: older adults with frailty / related measures.
- Intervention: fisetin versus placebo oral capsule.
- Outcomes: inflammatory markers, frailty, insulin resistance, and bone resorption.
- Update status: last update posted 2025-11-20.

## Caveats

- No cognitive endpoint is the main readout here.
- This supports the statement that fisetin is still a frailty / inflammaging program, not a cognition program.
