# Investigating the role of expectancy in caffeine withdrawal using the balanced placebo design

- PMID: 30861208
- PubMed: https://pubmed.ncbi.nlm.nih.gov/30861208/
- Ingested: 2026-04-28

## Summary

Balanced-placebo study in abstinent regular coffee consumers that separated caffeine dose from dose expectancy. Expectancy affected craving, but withdrawal symptoms and cognitive performance were driven mainly by the pharmacology of caffeine deprivation itself. This is a clean example of how withdrawal reversal can masquerade as benefit in a self-study.

## Notes

- Useful for any protocol that changes caffeine habit, stimulant exposure, or sleep pressure.
- Suggests that a detector should ask whether the active condition is merely relieving an induced deficit.
