# Association between dietary spermidine intake and cognitive performance in older adults

- PMID: 40180050
- PubMed: https://pubmed.ncbi.nlm.nih.gov/40180050/
- Ingested: 2026-04-28

## Summary

2025 NHANES analysis in adults 60+ found higher dietary spermidine intake associated with better performance across recall, fluency, digit-symbol substitution, and composite cognition. This is observational, so it supports plausibility rather than causality.
