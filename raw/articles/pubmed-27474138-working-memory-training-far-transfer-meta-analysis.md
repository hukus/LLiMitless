# Working Memory Training Does Not Improve Performance on Measures of Intelligence or Other Measures of Far Transfer

- PMID: 27474138
- PubMed: https://pubmed.ncbi.nlm.nih.gov/27474138/
- Ingested: 2026-05-03

## Summary

Meta-analysis arguing that working-memory training improves performance on tasks similar to the trained task but does not produce reliable far-transfer gains to intelligence, reading, arithmetic, or other broad cognitive outcomes. The practical read is that near-transfer task training should not be treated as a general IQ-enhancement method.

## Notes

This is the main counterweight to simple "train working memory to raise IQ" proposals. It supports a strategy-and-assessment proposal only when the claim is measured score improvement, not general intelligence.
