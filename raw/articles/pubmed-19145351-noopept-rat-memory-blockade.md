# Noopept Prevents Memory Deficit in Rats With Cholinergic Blockade

- PMID: 19145351
- PubMed: https://pubmed.ncbi.nlm.nih.gov/19145351/

## Summary

This rat study tests noopept against scopolamine and mecamylamine-induced memory impairment and reports prevention of the induced deficits. It is a preclinical antiamnesic signal, useful for understanding the nootropic lore around noopept, but it does not establish healthy-adult cognition efficacy in humans.

## Notes

- Source type: preclinical animal study.
- Evidence tier: preclinical, not human cognition.
- Claimed domain: memory deficit prevention and cholinergic blockade rescue.
- Interpretation: supports the mechanistic/nootropic narrative, but only in animals.
- Safety / status: human translation remains uncertain.
