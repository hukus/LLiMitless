# Post-Session Administration of USP Methylene Blue Facilitates the Retention of Pathological Fear Extinction and Contextual Memory in Phobic Adults

- PMID: 25018057
- PubMed: https://pubmed.ncbi.nlm.nih.gov/25018057/
- Ingested: 2026-04-27

## Summary

Randomized double-blind trial in 42 adults with marked claustrophobic fear. A 260 mg oral MB dose given immediately after extinction training improved later fear-extinction retention and contextual memory when the initial exposure session was successful, but could worsen follow-up fear when extinction was weak. This is one of the clearest human demonstrations that MB can modulate memory consolidation, but only in a narrow post-learning context.
