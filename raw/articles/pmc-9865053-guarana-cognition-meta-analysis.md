# Effect of Guarana on Cognitive Performance: A Systematic Review and Meta-Analysis

- Source type: open-access systematic review and meta-analysis.
- Publication: Nutrients, 2023.
- Date checked: 2026-05-03.

This review/meta-analysis evaluated guarana / Paullinia cupana for cognitive performance. Guarana is caffeine-containing and also contains other bioactive compounds, so any cognition signal needs caffeine-adjusted interpretation before it can be treated as distinct from [[caffeine]].

Use in the wiki: guarana watchlist anchor. The compound belongs in plant-product and stimulant-confound routing rather than standalone nootropic ranking.
