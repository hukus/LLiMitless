# 7,8-Dihydroxyflavone improves memory consolidation processes in rats and mice

- PMID: 24070857
- DOI: 10.1016/j.bbr.2013.09.029
- Publication: Behavioural Brain Research, 2013
- Evidence tier: preclinical cognition / rodent memory

## Summary

This paper tested 7,8-DHF in object recognition and object-location memory paradigms. In healthy rats, dosing immediately after learning or three hours after learning improved object memory formation. In APPswe/PS1dE9 mice and wild-type littermates, 7,8-DHF improved spatial object-location memory.

The paper matters because it frames 7,8-DHF as a consolidation-stage plasticity candidate rather than merely a disease-neuroprotection molecule. The same source also warns, by its design, that the evidence remains animal-only and acute/symptomatic in interpretation.

## Wiki Use

- Use for a `consolidation, not acute arousal` hypothesis.
- Keep as rodent-only evidence.
- Do not translate the dose, route, or timing into self-use guidance.
