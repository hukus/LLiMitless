# FDA food-substance inventory note for N,N-dimethylphenethylamine

FDA's Substances Added to Food inventory has an entry for N,N-DIMETHYLPHENETHYLAMINE. This is a food-ingredient / packaging-inventory style source, not a cognition-efficacy source.

Wiki use: this keeps the flavoring / food-substance context separate from high-dose nootropic, preworkout, or fat-loss supplement use. A food-substance inventory entry should not be used to infer that [[nn-dimethylphenethylamine-eria-jarensis]] is safe or effective as a stimulant-dose cognitive enhancer.
