# Unraveling the neurophysiological correlates of phase-specific enhancement of motor memory consolidation via slow-wave closed-loop targeted memory reactivation

Nature Communications 2025 study in 31 healthy young adults. Slow-wave closed-loop targeted memory reactivation was delivered at the up phase versus the down phase versus no reactivation during overnight sleep.

Up-phase cueing improved post-sleep motor performance more than down-phase cueing. The up condition also showed higher slow-oscillation amplitude and greater peak-nested sigma power, with task-related fMRI changes in striato-motor and hippocampal networks.

This is the strongest recent closed-loop TMR behavioral paper in the set because it links phase timing to both sleep physiology and motor performance. The main limitation is that it is a focused motor-learning task in a healthy young sample, not a broad cognition endpoint.
