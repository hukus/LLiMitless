# Cerebrolysin Ameliorates Age-Induced Dendritic Spine Degeneration and Memory Decline in C57BL6 Mice.

- PMID: 41460391
- PubMed: https://pubmed.ncbi.nlm.nih.gov/41460391/
- Ingested: 2026-04-26

## Summary

Mouse study reporting that chronic cerebrolysin improved short-term memory in some aged mice and increased hippocampal spine density in a region- and age-dependent manner.
