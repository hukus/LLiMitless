# Transcranial Direct Current Stimulation Does Not Increase Auditory False Perceptions in Healthy Participants

- PMID: 41449818
- PubMed: https://pubmed.ncbi.nlm.nih.gov/41449818/
- Ingested: 2026-04-30

## Summary

tDCS did not increase auditory false perceptions in healthy participants, even when the montage mimicked a hallucination-oriented model. This is a useful null because it shows a mechanistic, model-driven montage does not automatically produce the expected cognitive-perceptual effect.

## Notes

The abstract describes a signal-detection task in 104 healthy participants and a real-versus-sham crossover with a montage intended to mimic the hypertemporal/hypofrontal model in half the sample. That makes it a clean contradiction source for over-interpreting model-shaped montages.
