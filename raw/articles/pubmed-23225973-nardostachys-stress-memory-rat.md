# Nardostachys jatamansi extract prevents chronic restraint stress-induced learning and memory deficits in a radial arm maze task

- PMID: 23225973
- Evidence layer: preclinical animal cognition / stress model

## Summary

This preclinical paper studied Nardostachys jatamansi extract in a chronic restraint stress model and measured learning and memory deficits in a radial arm maze task. It is useful as a direct animal cognition/stress anchor for Jatamansi claims.

The translational boundary is strict: this is not a human cognition trial and should be treated as preclinical evidence only.
