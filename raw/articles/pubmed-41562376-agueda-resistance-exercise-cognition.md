# Effect of a 24-week resistance exercise intervention on cognitive function in cognitively normal older adults: The AGUEDA randomized controlled trial

- PMID: 41562376
- PubMed: https://pubmed.ncbi.nlm.nih.gov/41562376/
- Ingested: 2026-04-27

## Summary

24-week randomized resistance-exercise trial in cognitively normal older adults. The exercise arm improved overall executive function within-group, but the between-group effect was not significant; attentional/inhibitory control was the clearest domain signal.

## Notes

Useful as a modern exercise comparator: there is some domain-specific signal, but it is not a clean universal cognition win.
