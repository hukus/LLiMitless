# Notes
- Source: 1984 DDAVP study in healthy young male adults.
- Outcome: DDAVP improved memory for implicational sentences versus controls.
- Interpretation: early positive human signal, but small and old enough to need replication scrutiny.
- Relevance: this is one of the classic papers behind the vasopressin/desmopressin memory reputation.
- Caveat: sexual-dimorphism and task-specificity limit generalization.
