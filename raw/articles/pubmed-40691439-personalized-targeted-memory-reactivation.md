# Personalized targeted memory reactivation enhances consolidation of challenging memories via slow wave and spindle dynamics

- PMID: 40691439
- DOI: 10.1038/s41539-025-00340-3
- PubMed Central: https://pmc.ncbi.nlm.nih.gov/articles/PMC12280145/
- Published: 2025-07-22

## Summary

2025 npj Science of Learning study in 36 healthy adults. Personalized targeted memory reactivation adjusted cue counts by recall difficulty during stable NREM 2 and NREM 3 sleep. The result is best read as a proof-of-concept that personalization can improve consolidation for challenging memories, not as a broad cognition enhancer claim.
