# Dynamic brain connectivity patterns induced by oxytocin: An fMRI Co-Activation pattern analysis study

- PMID: 41876708
- PubMed: https://pubmed.ncbi.nlm.nih.gov/41876708/
- Publication date: 2026-03-24

## Summary

Randomized human fMRI study of a single intranasal oxytocin dose in healthy young and older adults. The main signal is target-engagement / network dynamics, not a direct cognition endpoint.

## Notes

- Source type: randomized human neuroimaging study.
- Sample size: 44 younger adults and 43 older adults.
- Intervention: single intranasal oxytocin 24 IU vs placebo, using the SDIOA dataset.
- Main result: oxytocin altered dynamic CAP metrics, including frequency, in-degree, and out-degree across multiple brain states.
- Interpretation: supports age- and state-dependent network modulation, but does not by itself establish broad cognitive enhancement.
