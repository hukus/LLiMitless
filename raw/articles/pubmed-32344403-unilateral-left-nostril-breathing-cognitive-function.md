# Effect of Unilateral Left Nostril Breathing (Chandra Anga Pranayama) on Cognitive Function in Healthy Yoga-Naive Individuals: A Randomized, Controlled, Pilot Study

- PMID: 32344403
- PubMed: https://pubmed.ncbi.nlm.nih.gov/32344403/
- Ingested: 2026-04-28

## Summary
In healthy yoga-naive students, 15 minutes of unilateral left nostril breathing did not outperform breath awareness on cognition. Memory improved within both groups, but attention and executive function did not separate. This is a useful null for the breath-protocol lane.
