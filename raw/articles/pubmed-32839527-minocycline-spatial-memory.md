# Minocycline differentially modulates human spatial memory systems

2020 Neuropsychopharmacology randomized crossover study in healthy male volunteers. Participants received minocycline 150 mg twice daily for 3 days versus placebo before an fMRI virtual-navigation task. The study was designed to test whether centrally penetrant minocycline would modulate hippocampal versus striatal memory systems.

Key readout: minocycline biased participants toward boundary-based navigation and marginally improved boundary-object performance, but it impaired landmark-based navigation more strongly, producing an overall spatial-memory performance decrease. fMRI showed reduced right caudate activity during memory encoding and no significant hippocampal benefit.

Interpretation for the wiki: this is a direct healthy-human cognition counterweight. Minocycline may alter neuroimmune-linked memory systems, but it should not be treated as a broad cognitive enhancer or clean brain-fog clearance tool.

Relevance: direct human cognition evidence and safety/endpoint caution for [[minocycline]] and the neuroimmune brain-fog chemical guide.
