# Phosphatidylserine containing omega-3 fatty acids: open-label extension in nondemented elderly with memory complaints

## Bibliographic snapshot

- Karger / Dementia and Geriatric Cognitive Disorders 2014 open-label extension paper.
- PubMed ID: 24577097.
- DOI: 10.1159/000357793.
- Product class: phosphatidylserine enriched with docosahexaenoic acid (PS-DHA).

## Study design

- Participants came from a core randomized study in which 157 nondemented individuals with memory complaints received PS-DHA 300 mg/day or placebo for 15 weeks.
- 122 completers continued into a 15-week open-label extension without breaking blinded treatment code.
- Open-label extension dose: 100 mg/day PS-DHA.
- Efficacy was assessed using a computerized cognitive tool and Clinical Global Impression of Change.

## Results captured

- The abstract reports significant improvement in sustained attention and memory recognition in the PS-DHA-naive group.
- PS-DHA continuers maintained cognitive status.
- Clinical Global Impression of Change improved in the naive group.

## Wiki interpretation

- This supports the idea that PS-DHA may affect selected attention/memory measures in older people with memory complaints.
- Because the extension was open-label, it is weaker than the blinded phase and should not be used as standalone proof.
- It is formulation-specific: PS-DHA should not be collapsed into all soy/sunflower PS, lecithin, DHA, or generic omega-3 supplements.
