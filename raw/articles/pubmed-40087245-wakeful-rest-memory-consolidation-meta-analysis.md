# Effects of wakeful rest on memory consolidation: A systematic review and meta-analysis

- PMID: 40087245
- PubMed: https://pubmed.ncbi.nlm.nih.gov/40087245/

## Summary

2025 systematic review and meta-analysis indicating that wakeful rest can support memory consolidation. For the endpoint dictionary, it strengthens the idea that consolidation is a distinct delayed-retention endpoint rather than just another same-day performance metric.

## Notes

Useful when distinguishing same-session throughput from post-encoding retention.
