# Evidence for indirect strengthening through reactivation of contextually bound memories

- PMID: 40269229
- PubMed: https://pubmed.ncbi.nlm.nih.gov/40269229/
- Published: 2025-04-23

## Summary

2025 Communications Psychology study across four experiments (n = 238). Reactivating a consolidated target memory improved retention of both the target and other memories acquired in the same context, but not memories learned in a different context.

## Notes

This is a context-dependent consolidation result, not a universal plasticity boost. It supports the idea that offline retrieval can spread benefit across a local memory neighborhood.
