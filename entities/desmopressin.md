# Desmopressin

## Bottom Line

Desmopressin / DDAVP is a safety-first old-memory comparator, not a modern nootropic. Medicinal cognition signal is `low/contested`: one old DDAVP memory paper was positive, one vasopressin/desmopressin healthy-volunteer trial was negative, and later vasopressin memory work stayed narrow or mixed. Anecdotal signal is `weak` for nootropic memory claims and `moderate` only for non-cognition POTS symptom-management discussion. Hyponatremia and water intoxication dominate the practical interpretation.

## What It Is

Desmopressin is a synthetic vasopressin analog used clinically for water-balance indications such as central diabetes insipidus. In this wiki it belongs with [[oxytocin-vasopressin-desmopressin-social-memory-2026-scan]], [[vasopressin]], [[oxytocin]], [[self-experimentation-stop-rules]], and [[negative-evidence-watchlist-for-cognition-interventions]] as a risk-heavy old nootropic-claim comparator.

## Medicinal Research Signal

The direct negative comparator is a double-blind study in 40 healthy volunteers comparing lysine vasopressin, desmopressin, and placebo. Nasal lysine vasopressin 23 IU/day or desmopressin 20 micrograms/day for 15 days did not significantly change verbal or visual memory scores versus placebo.^[raw/articles/pubmed-3762902-vasopressin-desmopressin-memory-healthy-volunteers.md]

The classic positive DDAVP source is a 1984 study in healthy young men that reported improved memory for implicational sentences. This helps explain the historical reputation, but it is old, narrow, and not enough to override the later negative comparator.^[raw/articles/pubmed-6494028-vasopressin-analog-ddavp-improves-memory-human-males.md]

The broader vasopressin memory trail adds context rather than confidence. A 1987 report described improved short-term recall and reduced alcohol-induced amnesia, while a three-month older-human vasopressin study found no general memory effect but mixed list-position changes. This is exactly the kind of old, task-specific pattern that should remain low-confidence.^[raw/articles/pubmed-3602225-vasopressin-memory-short-term-recall-alcohol-amnesia.md]^[raw/articles/pubmed-9364618-vasopressin-memory-older-humans.md]

## Safety And Status

The DailyMed label is the central interpretation gate. Desmopressin nasal spray is indicated for central diabetes insipidus, not cognition. The label contraindicates use in renal impairment or hyponatremia/history of hyponatremia, warns about fluid restriction and sodium monitoring, and notes unpredictable absorption with nasal-mucosa abnormalities. It also flags blood-pressure interactions with vasoconstrictors.^[raw/articles/dailymed-desmopressin-acetate-spray-label.md]

## Signal Judgment

Medicinal signal: `low/contested` for memory; old narrow positives counterweighted by a direct healthy-volunteer null.

Anecdotal signal: `weak` for cognition; `moderate` only for non-cognition POTS symptom anecdotes.

Practical route: risk-first / deprioritize as a nootropic; any use belongs in prescription and sodium-monitoring contexts, not self-experiment memory enhancement.
