# Citicoline

Citicoline, or CDP-choline, is a choline donor that should be tracked separately from [[alpha-gpc]], lysolecithin, phosphatidylcholine, and generic choline salts. The current wiki read is phenotype-bound: older-adult memory impairment and vascular / neurodegenerative cognitive impairment look more plausible than broad young-adult enhancement.

Medicinal signal: `low-moderate`. A 100-person randomized placebo-controlled trial in healthy older adults with age-associated memory impairment used 500 mg/day for 12 weeks and reported better episodic-memory and composite-memory secondary outcomes versus placebo. A 2023 review argues for consistent cognitive improvement in MCI, especially vascular-origin MCI, and tolerability without severe adverse events, but that is review-level synthesis rather than a new pooled estimate.^[raw/articles/pmc-8349115-citicoline-memory-healthy-older-adults.md]^[raw/articles/pubmed-36818199-citicoline-mci-review.md]

## Signal Split

| Layer | Signal | Readout |
|---|---|---|
| Age-associated memory impairment | `low-moderate` medicinal | 500 mg/day, 12-week RCT, secondary memory endpoints positive |
| Vascular / MCI review context | `low` medicinal | Review-level support, not a clean pooled trial estimate |
| Healthy young adults | `uncataloged` | Do not infer from older-adult impairment contexts |
| Anecdote | `weak` | Captured community data do not isolate citicoline well |

## Practical Interpretation

Citicoline belongs in [[choline-donor-cognition-signal-map]] as its own lane. It is not interchangeable with [[alpha-gpc]], and it should not be ranked above stimulant or cholinergic acute-attention comparators like [[nicotine]] without direct attention-task evidence in the target population.
