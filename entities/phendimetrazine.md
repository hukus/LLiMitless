# Phendimetrazine

Phendimetrazine is a prescription sympathomimetic anorectic in the same classic stimulant/diet-pill branch as [[phentermine]], [[diethylpropion]], and [[benzphetamine]]. For this wiki it is a safety and status comparator, not a cognitive-enhancement candidate.

## Current Read

Medicinal cognition signal: `risk-first / absent`. The captured label packet supports phendimetrazine as an anorectic / weight-reduction drug class member, with no captured healthy-adult cognition trial, brain-fog trial, or direct nootropic anecdote packet.^[raw/articles/dailymed-2026-sympathomimetic-anorectic-labels.md]

Class relevance: `stimulant-like but not proof-positive`. Phendimetrazine can sit near [[phentermine]] when users ask about prescription anorectic stimulants, but it should not inherit phentermine's old acute-task or sleep-deprivation evidence. It also should not be grouped casually with [[tesofensine]], which has a different monoamine-reuptake / long-half-life development profile.

## Label And Safety Layer

The DailyMed cluster places phendimetrazine with diethylpropion and benzphetamine as anorectic agents whose labels emphasize short-term weight-management framing, monotherapy / avoidance of other anorectic products, cardiovascular stimulation, pulmonary-hypertension and valvular-disease concern, hypertension caution, CNS-active-drug / alcohol caution, abuse/dependence, tolerance, and withdrawal after prolonged high-dose use.^[raw/articles/dailymed-2026-sympathomimetic-anorectic-labels.md]

The key wiki value is negative routing: phendimetrazine can explain why "phentermine-like" or "diet stimulant" anecdotes need molecule-specific evidence before being treated as cognition signals.

## Interpretation Gates

- Treat focus, energy, or less food noise as stimulant/appetite-state reports unless objective cognition endpoints are available.
- Do not borrow evidence from [[phentermine]], [[d-amphetamine]], [[methylphenidate]], or [[tesofensine]].
- Watch BP/HR, insomnia, agitation/anxiety, tolerance, dependence, withdrawal fatigue/depression, cardiovascular history, pulmonary hypertension / valvular-disease concern, alcohol, MAOIs, other stimulants, and calorie/hydration confounding.
