# Intepirdine

Intepirdine is a 5-HT6 receptor antagonist and dementia-program comparator. Its main value for the wiki is as a cross-phenotype failure anchor: it did not rescue the broader 5-HT6 cognition class after Alzheimer's disease programs had already disappointed.

Medicinal cognition signal: `negative`. In the HEADWAY-DLB randomized trial, intepirdine 35 mg/day or 70 mg/day for 24 weeks did not meet the primary UPDRS-III endpoint in dementia with Lewy bodies, and the other prespecified endpoints were also negative.^[raw/articles/pubmed-34189249-intepirdine-headway-dlb.md]

Class signal: `negative comparator`. The 2018 5-HT6 update still described attractive receptor biology, but it also treated late-stage idalopirdine and intepirdine failures as the key clinical warning for the class.^[raw/articles/pubmed-29848076-role-5ht6-receptor-antagonists-update.md]

## Safety And Interpretation Caveats

- Gastrointestinal adverse events were somewhat more common than placebo in HEADWAY-DLB, but the decisive issue for the cognition wiki is endpoint failure.
- Dementia with Lewy bodies is not the same phenotype as Alzheimer's disease, so intepirdine should be used as a cross-phenotype negative comparator rather than collapsed into one AD-only row.
- Motor or global clinical-state endpoints should not be rewritten as cognitive enhancement unless a prespecified cognitive endpoint separates.
